#  Raxena Website

A modern and responsive construction company website built using HTML, CSS. 
It features multiple pages, responsive layouts, service showcases, team profiles, contact sections, and a clean user interface for an enhanced user experience.

##  Features

- Responsive Design
- Home Page
- About Us
- Services Section
- Team Section
- Blog Section
- Contact Section
- Modern User Interface
- Smooth Navigation

##  Technologies Used

- HTML5
- CSS3
